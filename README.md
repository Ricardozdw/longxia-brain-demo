# 🦞 龙虾脑 MVP Demo

在手机网页上说一句话，驱动一台电脑（本 Demo 为 Mac）完成任务，并在手机上实时看到执行状态和结果。

交互形式是一个**对话式的个人 Agent**：像聊天一样说需求，执行过程折叠为一行实时状态，完成后用一句话回复结果（附截图 / 会议号），信息不全时会追问并记住上下文。

已支持两个场景：
- 🎬 **搜索一部热门电影并播放相关视频**：自动从豆瓣热门榜挑片，在 Chrome 中播放哔哩哔哩预告片；
- 📞 **加入腾讯会议 / 创建腾讯会议**：按会议号入会，或一键开快速会议并把会议号发回手机。
- ⏹ **关闭与退出**：暂停/继续/关闭视频，退出/结束会议，或只说「关闭」由 Agent 判断关什么。

产品方案见 [docs/产品方案.md](docs/产品方案.md)，录屏脚本见 [docs/录屏脚本.md](docs/录屏脚本.md)。

**演示视频**：[demo-video/龙虾脑-演示视频.mp4](demo-video/龙虾脑-演示视频.mp4)（1 分钟，iPhone 镜像实录：放电影 → 一键关闭 → 开会并回传会议号 → 一键离会 → 无效会议号拦截 → 清空记录）。

## 一、环境要求
| 依赖 | 说明 |
|---|---|
| macOS | 已在 macOS 15（Apple Silicon）验证 |
| Node.js ≥ 20 | `brew install node` 或 https://nodejs.org |
| Google Chrome | 场景一用于播放视频 |
| 腾讯会议客户端（已登录） | 场景二；已在 3.36 版验证 |
| 手机与电脑在同一 Wi-Fi | 手机通过局域网访问 |

## 二、启动（3 步）

**1. 安装依赖（首次）**
```bash
npm install
```

**2. 开启系统权限（首次，仅「创建会议」需要）**

系统设置 → 隐私与安全性 → **辅助功能** → 点「+」添加「终端」（/System/Applications/Utilities/Terminal.app）并打开开关，然后 Cmd+Q 重启终端。

> 用途：点击腾讯会议首页的「快速会议」按钮、读取会议号。不开也能运行，只是「创建会议」会失败并提示原因。

**3. 启动**

双击项目根目录的 **`启动龙虾脑.command`**（或在终端运行 `npm start`）。启动后会自动打开后台：

- 电脑后台看板：http://localhost:4320/admin
- 手机：用手机扫描后台右上角的二维码（即完成绑定），之后直接打开即可使用

> 第一次双击 .command 文件若提示“无法验证开发者”，请右键 → 打开。

## 三、验收清单

| # | 在手机上发送 | 预期结果 |
|---|---|---|
| 1 | 搜索一部热门电影并播放相关视频 | 选中豆瓣热门第 1 名 → 电脑 Chrome 播放 B 站预告片（网页全屏）→ 手机显示每步进度、结果和电脑画面截图 |
| 2 | 播放《哪吒之魔童闹海》的预告片 | 按指定片名搜索并播放 |
| 3 | 加入腾讯会议，会议码1234 | 立即提示「会议号格式错误：腾讯会议号应为 9 位数字」 |
| 3+ | 接着只回复一串 9 位数字 | Agent 结合上下文理解为“加入这个会议”（多轮补充） |
| 4 | 创建一个腾讯会议 | 电脑开启快速会议，手机显示会议号并可一键复制 |
| 5 | 加入腾讯会议 123 456 789（换成真实会议号） | 电脑自动入会，手机显示“已进入会议” |
| 6 | 电脑已在会议中时再发 4 或 5 | 提示「电脑正在会议中」，不会打断当前会议 |
| 6+ | 暂停 / 继续播放 / 关闭视频 | 控制电脑上正在播放的视频（也可点结果下方的快捷按钮） |
| 6++ | 退出会议 / 结束会议 | 电脑离开会议；主持人可「全员结束会议」 |
| 6+++ | 只说「关闭」或「退出」 | 自动判断电脑在做什么：在开会就离会、在放视频就关掉；都没有则如实告知 |
| 7 | 帮我订一张去上海的机票 | 提示暂不支持，并列出能做的事 |
| 8 | 在终端按 Ctrl+C 停掉服务后再看手机 / 或只结束助手进程后发任务 | 手机顶部显示「电脑离线」，任务提示离线并可重试 |

手机页面右上角「清空记录」可清空对话（点两次确认；后台统计不受影响）。

后台看板会随手机操作实时刷新：KPI、7 天趋势、转化漏斗、场景成功率、失败原因 Top、任务明细。

## 四、常用命令
```bash
npm start          # 启动服务端 + 电脑端助手
npm run seed       # 生成 7 天模拟历史数据（看板演示用，带「模拟」标记，可在看板开关中排除）
npm run seed -- --clear   # 删除模拟数据
npm run reset      # 清空真实任务记录和截图（录屏前用，需先停服务）
npm test           # 意图解析单元测试
```

单独演示“电脑离线”：分别在两个终端运行 `npm run server` 和 `npm run agent`，结束后者即可。

## 五、可选：接入大模型
复制 `.env.example` 为 `.env`，填写任意兼容 OpenAI 协议的接口（DeepSeek、通义、Kimi 等）。不配置时使用本地规则解析，两个场景完全可用。模型只负责“理解”，结果仍经过规则校验后才会驱动电脑。

## 六、项目结构
```
src/
  server.mjs          服务端：任务状态机、设备心跳、实时推送（SSE）、接口
  intent.mjs          意图解析（规则 + 可选大模型）、执行步骤定义、统一异常码
  launch.mjs          一键启动服务端 + 助手
  agent/
    agent.mjs         电脑端助手：心跳、领取任务、回传进度
    video.mjs         场景一：Playwright 驱动 Chrome 搜索并播放
    hot-movies.mjs    豆瓣热门榜（失败兜底内置片单）
    meeting.mjs       场景二：腾讯会议入会 / 创建
public/               手机端页面（mobile.*）与运营后台（admin.*）
scripts/              模拟数据、重置
docs/                 产品方案、录屏脚本
.runtime/             运行数据（任务记录、截图、浏览器配置），可随时删除
```

## 七、常见问题
- **手机打不开**：确认手机和电脑在同一 Wi-Fi；macOS 防火墙弹窗时选「允许」；公司网络可能隔离设备，可改用手机热点。
- **创建会议失败「缺少辅助功能权限」**：按第二步给「终端」开权限，并完全退出终端后重新双击启动。
- **创建会议失败「没有找到首页」**：请让腾讯会议停在首页（登录状态、无弹窗）。
- **创建会议时其他窗口被隐藏**：腾讯会议窗口被遮挡时，Agent 会用腾讯会议自带的「隐藏其它」腾出视野再点击，其他应用只是隐藏（未关闭），点 Dock 图标即可恢复。
- **视频未自动播放**：B 站偶尔要求登录或有弹窗，可在弹出的 Chrome 中登录一次，登录态会保留在 `.runtime/chrome-profile`。
- **端口被占用**：设置 `PORT=4330 npm start`。

## 八、已知限制
- 「快速会议」按钮为腾讯会议自绘控件，按首页窗口内相对位置点击，适配 3.x 版首页布局；客户端大改版时需重新校准。
- 入会时摄像头/麦克风遵循腾讯会议客户端自身设置，建议演示前在腾讯会议设置中关闭「入会开启摄像头」。
- 手机需与电脑同一局域网；产品化阶段通过云端中转解决。
